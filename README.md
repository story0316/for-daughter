# 딸을 위한 미니 게임 모음

빌드 과정 없이 정적 파일만으로 동작하는 모바일 웹 게임 모음입니다. 루트의 `index.html`은 게임을 고르는 홈 화면이고, 각 게임은 하위 폴더에 독립적으로 들어 있습니다.

## 홈 화면 (`/`)

네 게임 중 하나를 골라 들어갈 수 있는 넷플릭스 스타일 카드 캐러셀 화면입니다.

- `index.html` — 게임 선택 화면
- `style.css` — 홈 화면 스타일

## 1. 벚꽃길 숨은그림찾기 (`/hidden-picture/`)

벚꽃길을 배경으로 화면을 터치해서 숨은 그림을 찾는 게임입니다. 총 5개 판으로 구성되어 있습니다.

- `hidden-picture/index.html` — 화면 구조 (시작 / 게임 / 클리어 / 완료 화면)
- `hidden-picture/style.css` — 스타일
- `hidden-picture/script.js` — 배경/숨은 그림 렌더링, 터치 판정, 게임 진행 로직

## 2. 구구단 맞추기 (`/multiplication-quiz/`)

하트 3개로 시작해서 구구단 문제를 맞히는 게임입니다. 이지(2~5단, 4지선다) → 노말(2~9단, 4지선다) → 하드(2~9단, 직접 입력) 순으로 난이도가 올라가며, 틀리거나 시간 초과되면 하트를 잃고, 하트를 모두 잃으면 게임이 끝납니다.

- `multiplication-quiz/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `multiplication-quiz/style.css` — 스타일
- `multiplication-quiz/script.js` — 문제 생성, 정답 판정, 타이머, 하트/점수 로직

## 3. 스도쿠 (`/sudoku/`)

9×9 스도쿠 퍼즐 게임입니다. 하트 3개로 시작해서 가로/세로/3×3 박스에 1~9가 겹치지 않게 채우면 클리어입니다. 쉬움(빈칸 41개) → 보통(빈칸 49개) → 어려움(빈칸 55개) 순으로 난이도가 올라가며, 오답을 입력하면 하트를 잃고 하트가 모두 없어지면 게임이 끝납니다. 힌트는 판마다 3번까지 쓸 수 있습니다.

- `sudoku/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `sudoku/style.css` — 스타일
- `sudoku/script.js` — 퍼즐 생성(유일해 보장), 입력/충돌 판정, 힌트, 타이머, 하트 로직

## 4. 수학 프린세스 메이커 (`/math-princess/`)

프린세스 메이커 스타일의 육성 시뮬레이션입니다. 한 턴은 한 달이며 총 24턴(2년) 동안 매달 공부 / 알바 / 운동 / 휴식 / 친구 만나기 중 하나를 선택합니다. 돈을 벌려면(공부·알바) 수학 문제를 풀어야 하며, 문제는 초등 사칙연산부터 분수·방정식·함수·도형·확률·수열·삼각함수·미적분·심화(조합) 문제까지 레벨 1~10으로 자동 생성됩니다. 정답을 맞히면 골드·지능이 오르고 콤보가 쌓일수록 보상이 커지며, 틀리면 체력이 깎이고 스트레스가 오르며 콤보가 초기화됩니다. 지능이 높아질수록 더 높은 레벨의 공부가 열립니다.

이렇게 번 돈은 상점에서 장비(샤프/태블릿/노트북/AI 학습기)와 집(아파트/단독주택)을 사는 데 쓸 수 있고, 각각 골드·지능 획득량이나 휴식 효과를 영구적으로 강화합니다. 매력·창의력·지능을 섞은 "품위" 점수가 오르면 입는 옷이 평범한 옷 → 단정한 옷 → 예쁜 드레스 → 공주 드레스로 바뀌고, 만날 수 있는 사람도 친구/라이벌/선생님에서 시작해 사교계 친구·왕자님·왕실 스승까지 점점 넓어집니다. 특정 인물과 호감도를 80 이상 쌓으면 그 관계로 이어지는 히든 엔딩이 열리며, 그중 왕자님과 가까워지고 품위까지 충분히 쌓으면 최고 엔딩인 "진짜 공주가 되다"에 도달합니다.

24턴이 끝나면 최종 능력치(지능/집중력/체력/매력/창의력/스트레스/행운)와 인물 호감도에 따라 17가지 엔딩 중 하나로 마무리됩니다. `?turns=N` 쿼리 파라미터로 총 턴 수를 조절할 수 있습니다(테스트/데모용).

- `math-princess/index.html` — 화면 구조 (시작 / 메인 허브 / 학원(레벨) 선택 / 문제풀이 / 세션 요약 / 이벤트 / 엔딩)
- `math-princess/style.css` — 스타일
- `math-princess/problems.js` — 레벨별 문제 생성 엔진(플러그인 방식, DOM 비의존), 정답 판정
- `math-princess/endings.js` — 최종 능력치 기반 엔딩 판정 로직(DOM 비의존)
- `math-princess/script.js` — 하루(턴) 진행, 활동별 능력치/골드 반영, 콤보, 랜덤 이벤트, 로컬 저장/이어하기

`problems.js`와 `endings.js`는 DOM에 의존하지 않는 순수 로직이라 Node.js에서 바로 불러와 유닛 테스트할 수 있습니다(레벨 1~10 문제 수백 개 자동 채점, 엔딩 판정 케이스 검증 완료).

각 게임 화면 왼쪽 위의 "🏠 홈으로" 버튼을 누르면 다시 게임 선택 화면으로 돌아옵니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 후, 홈 화면에서 원하는 게임을 골라 플레이하면 됩니다. (모바일 화면 크기에서 가장 잘 보입니다.)
