# 딸을 위한 미니 게임 모음

빌드 과정 없이 정적 파일만으로 동작하는 모바일 웹 게임 모음입니다. 루트의 `index.html`은 게임을 고르는 홈 화면이고, 각 게임은 하위 폴더에 독립적으로 들어 있습니다.

## 홈 화면 (`/`)

네 게임 중 하나를 골라 들어갈 수 있는 넷플릭스 스타일 카드 캐러셀 화면입니다.

- `index.html` — 게임 선택 화면
- `style.css` — 홈 화면 스타일

## 1. 벚꽃길 숨은그림찾기 (`/hidden-picture/`)

벚꽃길을 배경으로 화면을 터치해서 숨은 그림을 찾는 게임입니다. 총 5개 판으로 구성되어 있습니다.

- `hidden-picture/index.html` — 화면 구조 (시작 / 게임 / 클리어 / 완료 화면)
- `hidden-picture/style.css` — 스타일
- `hidden-picture/script.js` — 배경/숨은 그림 렌더링, 터치 판정, 게임 진행 로직

## 2. 구구단 맞추기 (`/multiplication-quiz/`)

하트 3개로 시작해서 구구단 문제를 맞히는 게임입니다. 이지(2~5단, 4지선다) → 노말(2~9단, 4지선다) → 하드(2~9단, 직접 입력) 순으로 난이도가 올라가며, 틀리거나 시간 초과되면 하트를 잃고, 하트를 모두 잃으면 게임이 끝납니다.

- `multiplication-quiz/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `multiplication-quiz/style.css` — 스타일
- `multiplication-quiz/script.js` — 문제 생성, 정답 판정, 타이머, 하트/점수 로직

## 3. 스도쿠 (`/sudoku/`)

9×9 스도쿠 퍼즐 게임입니다. 하트 3개로 시작해서 가로/세로/3×3 박스에 1~9가 겹치지 않게 채우면 클리어입니다. 쉬움(빈칸 41개) → 보통(빈칸 49개) → 어려움(빈칸 55개) 순으로 난이도가 올라가며, 오답을 입력하면 하트를 잃고 하트가 모두 없어지면 게임이 끝납니다. 힌트는 판마다 3번까지 쓸 수 있습니다.

- `sudoku/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `sudoku/style.css` — 스타일
- `sudoku/script.js` — 퍼즐 생성(유일해 보장), 입력/충돌 판정, 힌트, 타이머, 하트 로직

## 4. 프린세스 메이커 (`/math-princess/`)

프린세스 메이커 스타일의 육성 시뮬레이션입니다. 시작 화면에서 "새로 시작하기"를 누르기 전에 주인공 이름을 직접 지어줄 수 있고(비워두면 "우리 딸"), 그 이름이 메인 화면 캐릭터 카드에 표시됩니다. 이미 진행 중인 저장 데이터가 있는 상태에서 "새로 시작하기"를 누르면, 실수로 그동안의 진행 상황을 지우지 않도록 "정말 새로 시작할까요?" 확인 화면이 먼저 뜨고, 취소하면 기존 진행이 그대로 보존됩니다. 메인 화면은 원작처럼 **스케줄 / 실행 / 쇼핑 / 옷갈아입기 / 대화 / 상태** 6버튼 메뉴로 구성됩니다. "대화"는 턴을 소모하지 않고 한 달에 한 번 딸과 짧게 대화해 매력을 살짝 올릴 수 있는 가벼운 상호작용이고, "상태"에서는 전체 능력치, 인물별 호감도(잠긴 인물은 물음표로 표시), 보유 장비를 한 화면에서 확인할 수 있습니다.

"스케줄"은 한 달을 실제 생활 계획표처럼 **1~4주**로 나눠 각 주마다 활동(공부/알바/운동/휴식/빨래하기/텃밭 가꾸기/친구 만나기/연회 참석/왕국 수학경시대회)을 하나씩 배치하는 화면입니다. 각 주 칸을 탭하면 활동을 고를 수 있고, 화면 아래에는 "아직 지나지 않은 주"들에 배치한 활동을 기준으로 **이번 달에 능력치가 대략 얼마나 오를지 미리 계산해서 보여주는 예상 변화 패널**이 있어(정답률 75% 가정), 계획을 다 짜지 않고도 이번 주 배치를 바꿔가며 결과를 비교해볼 수 있습니다. 계획을 다 세운 뒤 메인 화면의 "실행"을 누르면 1주차부터 순서대로 그 주에 배치한 활동이 진행되고(각 주마다 다시 "실행"을 눌러 이어감), 4주를 모두 마쳐야 실제로 한 달(턴)이 넘어갑니다. 만약 특정 주에 배치한 활동을 조건 미달로 할 수 없다면(예: 골드 부족, 옷차림 미달) 안내와 함께 그 주는 그냥 넘어갑니다.

한 턴은 한 달이며 총 48턴(4년) 동안 진행됩니다. 돈을 벌려면(공부·알바) 문제를 풀어야 하며, 문제는 **수학·영어·과학** 세 과목이 매 문제마다 무작위로 섞여 나옵니다. 수학은 초등 사칙연산부터 분수·방정식·함수·도형·확률·수열과 로그·삼각함수와 벡터·심화(조합)까지 레벨 1~9, 과학은 초등학교 4학년부터 중학교 1학년 교과 범위로 레벨 1~4까지 자동 출제됩니다(과학: 물질의 상태·태양계·연소와 전기·광합성과 힘 등). 영어는 수학처럼 계속 어려워질 수 있도록 초4 기초 문법부터 고등학교 2학년 수준(강조구문·도치·수능형 어휘와 논리 추론)까지 레벨 1~8로 확장되어 있습니다. 정답을 맞히면 골드·지능(과 소량의 창의력)이 오르고 콤보가 쌓일수록 보상이 커지며, 틀리면 체력이 깎이고 스트레스가 오르며 콤보가 초기화됩니다. 지능이 높아질수록 더 높은 레벨의 문제가 열립니다. "공부"를 고르면 세션을 시작할 때 이번엔 어떤 과목을 공부할지 하나 정해져서(수학이면 수학만, 영어면 영어만) 그 세션 안에서는 계속 같은 과목이 이어지고, 레벨만 문제마다 살짝 오르내립니다("이번 주는 수학을 공부한다"는 느낌을 주기 위함). 반면 "알바"는 여러 과목의 쉬운 문제가 그때그때 섞여 나와 이런저런 잡일을 도맡는 느낌을 줍니다. 운동·휴식에도 보너스 문제가 1개씩 딸려 나와, 맞히면 추가 효과를 더 받을 수 있습니다(틀려도 원래 효과는 그대로 받으니 부담은 없습니다).

지능이 50 이상이면 스케줄에 "왕국 수학경시대회"도 고를 수 있습니다. 문제가 덧셈뺄셈(레벨 1)부터 시작해 현재 해금된 최고 레벨까지 점점 어려워지는 순서로 나오고, 상금도 문제가 어려워질수록 함께 커집니다(정답 즉시 지급, 문제를 전부 맞히면 가장 어려웠던 마지막 문제 수준에 비례한 만점 보너스까지). 일반 알바보다 훨씬 큰돈을 벌 수 있어 원하는 옷을 사기 위한 지름길이 되어주지만, 오답마다 스트레스가 쌓이는 활동이라 매주 반복하기보다는 가끔 도전하는 편이 유리합니다.

"공부"·"알바"·"왕국 수학경시대회"는 스케줄에서 고를 때 슬라이더로 문제 수(3~15개)를 직접 정할 수 있습니다. 기본 문제 수(각각 4/3/5개)를 그대로 두면 기존과 같은 보상이지만, 문제 수를 더 많이 고를수록 문제당 보상이 최대 1.5배까지 커지고(반대로 더 적게 고르면 조금 줄어듭니다), 그만큼 체력·스트레스 소모도 문제 수에 비례해 늘어납니다. 즉 짧게 여러 번 도전하기보다 한 번에 길게 몰아붙이는 쪽이 더 효율적이 되도록 만든 트레이드오프입니다.

문제를 풀 때 정답/오답을 확인한 뒤에는 예전처럼 자동으로 다음 문제로 넘어가지 않고, 화면에 뜬 "다음 →" 버튼을 직접 눌러야 다음 문제로 넘어갑니다(마지막 문제라면 결과 화면으로). 덕분에 정답 풀이와 설명을 충분히 읽고 자기 속도대로 진행할 수 있습니다. 문제가 잘 안 풀릴 때는 "💡 도움 받기" 버튼을 누르면 선생님 또는 왕실 스승이 나타나 그 문제를 어떻게 풀면 되는지 다른 숫자 예시를 들어 친절하게 힌트를 알려줍니다(정답을 그대로 알려주지 않고 풀이 방법만 알려줘서 스스로 계산해볼 수 있음). 수학 문제는 20가지 유형 전부에 풀이 예시가 준비되어 있고, 영어·과학·연회 예절 문제도 정답을 직접 말해주지 않으면서 힌트를 주는 문장이 준비되어 있습니다. 입력형 문제의 숫자 키패드에는 0~9와 지우기 외에도 -(음수)·+(양수)·.(소수)·/(분수) 버튼이 있어 "-3", "3/4" 같은 답도 그대로 입력할 수 있고, 답 입력창은 최대 12자까지 받을 수 있습니다.

무리하게 공부만 몰아붙이면 대가가 따릅니다. 스트레스가 70을 넘으면 그 정도에 비례해(최대 60%) 계획했던 활동 대신 몸살이 나 하루 앓아눕는 이벤트가 발생해, 체력이 줄고 그 주의 계획을 날리게 됩니다. 스트레스가 100에 가까워질수록 몸살이 날 확률도 함께 높아지므로, 공부·알바만 반복하기보다 중간중간 휴식으로 스트레스를 관리하는 편이 장기적으로 더 유리합니다. 또한 인물과의 특별한 이야기(선택지가 있는 경우) 중 절반 정도는 "더 화끈하지만 스트레스나 체력을 대가로 치르는 선택"과 "안전하지만 소소한 선택"으로 나뉘어 있어, 무조건 더 많이 오르는 쪽만 고르면 되는 게 아니라 지금 컨디션에 맞춰 고민하는 재미가 있습니다.

이렇게 번 돈은 상점의 "장비" 탭에서 학용품(샤프/태블릿/티아라/왕실 초대장/AI 학습기/개인 오케스트라 레슨)과 집(아파트/단독주택/별궁), 그리고 **하녀·정원사 고용**에 쓸 수 있습니다. "빨래하기"는 직접 하면 돈은 들지 않지만 몸이 힘들어 체력이 깎이고 스트레스가 쌓입니다(문제까지 맞히면 그나마 스트레스가 덜 쌓이고 골드도 조금 더 받습니다). 골드를 들여 하녀를 고용하면 이 수고를 자동화할 수 있어, 그렇게 아낀 주를 공부나 알바에 쓰면 결과적으로 더 많은 돈을 벌 수도 있는 트레이드오프입니다. "텃밭 가꾸기"는 반대로 직접 하면 수확물을 팔아 골드를 벌고 가끔 네잎클로버를 발견해 행운도 오릅니다(다른 능력치와 달리 행운을 꾸준히 키울 수 있는 사실상 유일한 활동). 정원사를 고용하면 골드와 행운 상승 모두 매턴 자동으로 적용되며 스케줄에서 사라집니다. 나머지 장비는 각각 골드·지능 획득량, 연회 매력 획득량, 인물 호감도 획득량, 휴식 효과를 영구적으로 강화합니다.

상점의 "직업" 탭에서는 스탯 요건을 만족하면 지원할 수 있는 정식 직업 3단계(동네 과외 선생님 → 왕실 도서관 사서 → 왕실 서기관)를 볼 수 있습니다. 매주 문제를 푸는 "알바"와 달리, 한 번 취업하면 스케줄과 무관하게 매턴 자동으로 급여가 들어오고 급여도 알바보다 훨씬 넉넉합니다. 급이 높은 직업일수록(사서·서기관) 왕자님과 관련된 호감도 보너스가 붙고, 궁에 드나들 일이 많아져 매턴 일정 확률로 왕자님과 우연히 마주치는 보너스 이벤트까지 생겨 관계 발전에도 실질적으로 도움이 됩니다. 마음이 바뀌면 재직 중인 직업 카드의 "그만두기" 버튼으로 언제든 그만두고 무직으로 돌아갈 수 있습니다.

"상태" 화면의 "📜 기초 과목 인증" 섹션에서는 수학·영어·과학 세 과목 각각에 대해 동메달(초4 수준) → 은메달(초5~중1 수준) → 금메달(중2~고1 수준) 인증 시험에 도전할 수 있습니다. 지능이 그 레벨에 도달했다고 자동으로 메달이 붙는 건 아니고, 실제로 그 레벨 문제 5개 중 4개 이상을 맞혀야 인증되며(통과하면 축하금도 받음), 떨어져도 이미 딴 등급이 깎이지는 않아 언제든 재도전할 수 있습니다. 과학은 아직 초4~중1(4단계) 콘텐츠만 있어서 은메달까지만 도전할 수 있고, 수학·영어는 더 어려운 문제까지 있어 금메달까지 도전할 수 있습니다. 이 시험은 스케줄에 배치하는 활동이 아니라 상태 화면에서 바로 응시하는 것이라 주/달을 소모하지 않습니다.

매력·창의력·지능을 섞은 "품위" 점수가 오르면 평범한 옷 → 단정한 옷 → 예쁜 드레스 → 공주 드레스 → 무도회 드레스 → (만점에서만 해금되는) 대관식 드레스 순서로 옷을 **살 수 있게**만 됩니다. 실제로 입으려면 상점의 "옷장" 탭에서 골드(400G~6,000G, 단계가 높을수록 비싸짐)를 내고 직접 사야 하며, 품위가 아무리 높아도 사지 않으면 저절로 입혀지지 않습니다(품위가 새 단계에 닿으면 "OO 구매 가능!" 토스트로 알려주기만 함). 산 옷은 이후 옷장에서 언제든 자유롭게 갈아입을 수 있고, 단계마다 실제로 그린 일러스트 초상화가 금색 액자 프레임에 담겨 표시됩니다(엔딩 판정과 인물 해금은 실제 품위 점수 기준이라 코스튬 변경과 무관하게 유지됨).

메인 화면은 서재풍 배경 일러스트 위에 캐릭터 초상화(금색 액자)와 6개 능력치를 한눈에 보여주는 미니 상태 패널, 그리고 반투명 유리 카드 스타일로 다시 디자인한 6버튼 메뉴가 겹쳐진 게임 인터페이스 형태입니다. 다른 화면으로 넘어가지 않고도 현재 능력치 성장을 바로 확인할 수 있어, 옛 프린세스 메이커 시리즈의 메인 화면 느낌을 살렸습니다.

지능/집중력/체력/매력/창의력/행운 6개 능력치는 값이 20/40/60/80을 넘을 때마다 Lv.1~5로 레벨업하며, 능력치 막대 색이 회색 → 파랑 → 보라 → 핑크 → 금색으로 단계적으로 화려해지고 화면 위에 "🎉 OO Lv.N 달성!" 토스트가 떠서 성장을 바로 체감할 수 있습니다(스트레스는 낮을수록 좋은 지표라 이 레벨업 시스템에서 제외). 활동을 하나 마치고 메인 화면으로 돌아오면, 그 활동으로 실제로 바뀐 능력치만 게이지바가 부드럽게 채워지며 반짝이고 그 옆에 "+3"/"-2"처럼 얼마나 바뀌었는지 잠깐 떠올랐다 사라지는 팝업이 붙어서, 방금 한 행동이 무엇을 얼마나 바꿨는지 한눈에 보입니다. 메인 화면 게이지바에는 현재 값(진한 색)에 겹쳐서, 이번 달 남은 계획을 스케줄대로 다 실행했을 때 대략 어디까지 오를지 보여주는 반투명한 예상 바도 함께 표시됩니다 — 스케줄 화면을 따로 열어보지 않아도 "이대로 하면 이만큼 자란다"가 바로 보여서 계획을 짤 동기부여가 됩니다.

만날 수 있는 사람도 친구/라이벌/선생님에서 시작해 사교계 친구·왕자님·왕실 스승까지 점점 넓어집니다. 특정 인물과 호감도를 80 이상 쌓으면 그 관계로 이어지는 히든 엔딩이 열리며, 그중 왕자님과 가까워지고 품위까지 충분히 쌓으면 최고 엔딩인 "진짜 공주가 되다"에 도달합니다. 인물 호감도는 숫자와 함께 삼국지 시리즈의 "친밀도"처럼 낯선 사이 → 아는 사이 → 친근한 사이 → 가까운 사이 → 각별한 사이 5단계 이름으로도 표시되며, 한동안 만나지 않고 방치한 인물은 호감도가 서서히 식으므로(2턴 이상 공백 시 매턴 소폭 감소) 꾸준히 자주 만나야 관계가 유지·발전합니다. 그 인물과 충분히 친해지면(호감도 50 이상) 그 인물이 등장하는 퀴즈에 은근슬쩍 힌트를 줘서 문제가 살짝 쉬워지고, 아주 친해지면(80 이상) 통과 기준도 하나 낮아져 그동안 쌓은 우정·인연이 실제로 도움이 되는 걸 체감할 수 있습니다.

스케줄의 "연회 참석"은 작은 다과회 → 사교 모임 → 고급 사교 모임 3단계로 나뉘며, 스케줄에서 활동을 고를 때 등급 선택 화면이 따로 뜹니다. 작은 다과회(입장료 100G)는 옷차림·품위 요건이 없어 누구나 바로 들어갈 수 있고, 사교 모임(입장료 200G)은 단정한 옷 이상과 품위 35 이상이 필요하며, 고급 사교 모임(입장료 400G)은 예쁜 드레스 이상·품위 70 이상에 더해 **영어 은메달 이상 인증**까지 있어야 초대받을 수 있습니다(요건 미달인 등급은 카드가 잠겨서 아예 고를 수 없음). 어느 등급이든 안에서는 실제 사교 예절(인사, 식사 예절, 경청, 감사 인사, 시간 약속 등)을 묻는 3문제짜리 객관식 퀴즈가 진행되어 정답을 맞힐 때마다 매력이 오르지만, 왕자님은 **고급 사교 모임에서만** 만날 수 있습니다 — 그 등급에서 3문제를 모두 맞히면(예쁜 드레스 이상은 입장 요건에 이미 포함되어 있어 자동으로 충족) 왕자님이 다가와 말을 걸어주며 호감도가 크게 오르고, 그 아래 등급에서는 만점을 받아도 매력만 오를 뿐 왕자님과는 만나지 못합니다. "친구 만나기"로 왕자님을 직접 찾아가 만나는 것도 마찬가지로 예쁜 드레스 이상을 입고 있어야 하며(품위 점수로 해금만 해두고 실제로는 다른 옷을 입고 있으면 만날 수 없음), 이 조건을 만족하면 품위·호감도 조건에 따라 순서대로 열리는 별도 이야기(호숫가에서 다친 강아지 돌보기 → 대무도회에서 함께 춤추기)로 더 깊은 관계를 쌓을 수 있어, 자연스럽게 예절을 익히고 옷차림을 갖추며 왕자님과 점점 가까워지는 재미를 줍니다.

"친구 만나기"에서 각 인물마다 조건(품위·능력치·다른 인물과의 호감도)을 만족하면 일반 대사 대신 한 번뿐인 특별한 이야기(퀴즈/1회성 이벤트/선택형 대화)가 먼저 진행됩니다. 정원에서 길 잃은 아기 고양이를 구해주는 이야기(친구), 라이벌과의 쿠키 만들기 대결과 퀴즈 대결, 사교계 친구의 다과회 초대 두 편, 왕실 스승님의 지혜 시험과 서고의 비밀, 왕자님과의 호숫가 산책·장미 정원 산책·대무도회, 친구의 생일 파티, 그리고 품위 만점에서 열리는 대관식 무도회까지 총 14편이 실제 일러스트와 함께 들어 있으며, 각 인물마다 조건을 만족하는 순서대로 이어지고 한 번 완료하면 이후에는 다시 일반 대사로 돌아갑니다.

배경음악도 들어 있습니다. 평소에는 기본 배경음악이 흐르다가, 왕자님과의 정원 산책·친구의 생일 파티·다과회(사교계 초대장/다과회 초대 두 편 모두)·대관식 무도회처럼 특별한 순간에는 그 이야기에 맞춘 곡으로 자연스럽게 바뀌고, 이야기가 끝나고 메인 화면으로 돌아오면 다시 기본 배경음악으로 돌아옵니다. 화면 오른쪽 위의 🔊 버튼으로 언제든 음소거할 수 있고, 이 설정은 다음에 접속해도 그대로 기억됩니다.

48턴이 끝나면 최종 능력치(지능/집중력/체력/매력/창의력/스트레스/행운)와 인물 호감도, 그리고 최종 골드에 따라 19가지 엔딩 중 하나로 마무리됩니다(지능·체력을 함께 키우면 "왕국의 재무장관", 스탯보다 알뜰한 살림과 꾸준한 벌이로 골드 4,000G 이상을 모으면 "소문난 재테크의 달인" 엔딩도 있습니다). `?turns=N` 쿼리 파라미터로 총 턴 수를 조절할 수 있습니다(테스트/데모용).

시작 화면의 "📖 엔딩 도감" 버튼을 누르면 지금까지 여러 판에 걸쳐 도달했던 엔딩을 전부 모아볼 수 있습니다. 아직 못 본 엔딩은 🔒 "???"로 잠겨 있어 스포일러 없이 "이번엔 뭘 노려볼까" 재도전 욕심을 자극하고, 새로운 엔딩에 처음 도달하면 엔딩 화면에 "🆕 새로운 엔딩을 발견했어요!" 배지가 뜹니다. 이 기록은 진행 중인 게임 저장과 별도로 관리되어, 새로 시작하거나 엔딩을 봐도 지워지지 않고 계속 쌓입니다.

- `math-princess/index.html` — 화면 구조 (시작 / 메인 허브 / 스케줄 / 상태 / 상점(장비·옷장) / 문제풀이 / 세션 요약 / 이벤트 / 선택형 이야기 / 엔딩)
- `math-princess/style.css` — 스타일
- `math-princess/problems.js` — 수학 레벨별(1~10) 문제 생성 엔진(플러그인 방식, DOM 비의존), 정답 판정
- `math-princess/subjects.js` — 영어·과학 레벨별(1~4, 초4~중1) 문제 생성 엔진(DOM 비의존). 정답 판정은 problems.js의 checkAnswer를 그대로 재사용

- `math-princess/portrait.js` — 품위 단계별 캐릭터 SVG 초상화 생성기(DOM 비의존, 실제 일러스트가 없을 때의 대체용, 0~5 총 6단계)
- `math-princess/scenarios.js` — 시나리오(quiz/narrative/branching) 콘텐츠용 표준 자료구조와 검증 함수(DOM 비의존). 실제 플레이 가능한 시나리오 14편 포함(새 예고편이 추가되면 상태 화면 "다가오는 이야기" 섹션에 잠금 카드로 미리 보여준다)
- `math-princess/question-engine.js` — "다음에 어떤 문제를 낼지"만 담당하는 순수 로직(DOM 비의존). 과목/레벨 선택, 문제 생성, 중복 방지. `createQuestionEngine({P,SUBJ})`로 만든다
- `math-princess/reward-engine.js` — "정답/오답에 얼마를 줄지"만 담당하는 순수 로직(DOM 비의존). 골드/스탯 공식, 콤보 배율, 장비 보너스, 호감도 증가량. 밸런스 수치를 조정할 때는 이 파일만 보면 된다. `createRewardEngine({ITEMS})`로 만든다
- `math-princess/game-engine.js` — question-engine.js/reward-engine.js를 조합해 세션 흐름·상점/옷장·시나리오·턴 진행·엔딩 등 게임 상태가 바뀌는 전체 흐름을 담당하는 오케스트레이션 엔진(DOM 비의존). `createEngine({P,SUBJ,SC,E})`로 만들며, script.js(브라우저 UI)와 밸런스 시뮬레이터(Node)가 완전히 같은 코드를 공유한다
- `math-princess/assets/scenarios/{id}/*.png` — 시나리오별 실제 일러스트 장면 이미지
- `math-princess/assets/portraits/tier0~5.png` — 품위 단계별 실제 일러스트 초상화(6단계 전부)
- `math-princess/assets/wardrobe/tier0~5.png` — 옷장 탭에 쓰이는 옷 썸네일 이미지(6단계 전부)
- `math-princess/assets/npcs/{id}.png` — 인물별 초상화(친구/라이벌/선생님/사교계 친구/왕자님/왕실 스승 6명 전부 적용됨)
- `math-princess/script.js` — game-engine.js를 호출해 화면을 그리는 UI 레이어. 스케줄/실행 메뉴, 옷장/상점, 상태 화면(다가오는 이야기 포함), 로컬 저장/이어하기, 배경음악 재생

`problems.js`/`subjects.js`/`endings.js`/`scenarios.js`/`question-engine.js`/`reward-engine.js`/`game-engine.js`는 DOM에 의존하지 않는 순수 로직이라 Node.js에서 바로 불러와 유닛 테스트할 수 있습니다.

`math-princess/test/`에 회귀 테스트 스위트가 있습니다(순수 로직 유닛 테스트, 48개월 x 4주 밸런스/엔딩 도달 가능성 시뮬레이션, Playwright 기반 e2e 테스트). 기능을 추가·수정한 뒤 `bash math-princess/test/run-all.sh`로 전부 돌려볼 수 있습니다. 자세한 내용은 `math-princess/test/README.md` 참고.

각 게임 화면 왼쪽 위의 "🏠 홈으로" 버튼을 누르면 다시 게임 선택 화면으로 돌아옵니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 후, 홈 화면에서 원하는 게임을 골라 플레이하면 됩니다. (모바일 화면 크기에서 가장 잘 보입니다.)
