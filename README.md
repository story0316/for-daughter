# 딸을 위한 미니 게임 모음

빌드 과정 없이 정적 파일만으로 동작하는 모바일 웹 게임 모음입니다. 루트의 `index.html`은 게임을 고르는 홈 화면이고, 각 게임은 하위 폴더에 독립적으로 들어 있습니다.

## 홈 화면 (`/`)

네 게임 중 하나를 골라 들어갈 수 있는 넷플릭스 스타일 카드 캐러셀 화면입니다.

- `index.html` — 게임 선택 화면
- `style.css` — 홈 화면 스타일

## 1. 벚꽃길 숨은그림찾기 (`/hidden-picture/`)

벚꽃길을 배경으로 화면을 터치해서 숨은 그림을 찾는 게임입니다. 총 5개 판으로 구성되어 있습니다.

- `hidden-picture/index.html` — 화면 구조 (시작 / 게임 / 클리어 / 완료 화면)
- `hidden-picture/style.css` — 스타일
- `hidden-picture/script.js` — 배경/숨은 그림 렌더링, 터치 판정, 게임 진행 로직

## 2. 구구단 맞추기 (`/multiplication-quiz/`)

하트 3개로 시작해서 구구단 문제를 맞히는 게임입니다. 이지(2~5단, 4지선다) → 노말(2~9단, 4지선다) → 하드(2~9단, 직접 입력) 순으로 난이도가 올라가며, 틀리거나 시간 초과되면 하트를 잃고, 하트를 모두 잃으면 게임이 끝납니다.

- `multiplication-quiz/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `multiplication-quiz/style.css` — 스타일
- `multiplication-quiz/script.js` — 문제 생성, 정답 판정, 타이머, 하트/점수 로직

## 3. 스도쿠 (`/sudoku/`)

9×9 스도쿠 퍼즐 게임입니다. 하트 3개로 시작해서 가로/세로/3×3 박스에 1~9가 겹치지 않게 채우면 클리어입니다. 쉬움(빈칸 41개) → 보통(빈칸 49개) → 어려움(빈칸 55개) 순으로 난이도가 올라가며, 오답을 입력하면 하트를 잃고 하트가 모두 없어지면 게임이 끝납니다. 힌트는 판마다 3번까지 쓸 수 있습니다.

- `sudoku/index.html` — 화면 구조 (시작 / 게임 / 결과 화면)
- `sudoku/style.css` — 스타일
- `sudoku/script.js` — 퍼즐 생성(유일해 보장), 입력/충돌 판정, 힌트, 타이머, 하트 로직

## 4. 프린세스 메이커 (`/math-princess/`)

프린세스 메이커 스타일의 육성 시뮬레이션입니다. 메인 화면은 원작처럼 **스케줄 / 실행 / 쇼핑 / 옷갈아입기 / 대화 / 상태** 6버튼 메뉴로 구성됩니다. "스케줄"에서 이번 달에 할 일(공부/알바/운동/휴식/친구 만나기)을 먼저 고르고 "실행"으로 실제 진행하는 2단계 방식이며, "대화"는 턴을 소모하지 않고 한 달에 한 번 딸과 짧게 대화해 매력을 살짝 올릴 수 있는 가벼운 상호작용입니다. "상태"에서는 전체 능력치, 인물별 호감도(잠긴 인물은 물음표로 표시), 보유 장비를 한 화면에서 확인할 수 있습니다.

한 턴은 한 달이며 총 48턴(4년) 동안 진행됩니다. 돈을 벌려면(공부·알바) 문제를 풀어야 하며, 문제는 **수학·영어·과학** 세 과목이 매 문제마다 무작위로 섞여 나옵니다. 수학은 초등 사칙연산부터 분수·방정식·함수·도형·확률·수열·삼각함수·미적분·심화(조합)까지 레벨 1~10, 영어·과학은 초등학교 4학년부터 중학교 1학년 교과 범위로 레벨 1~4까지 자동 출제됩니다(영어: 어휘·문법·시제·관계대명사·숙어, 과학: 물질의 상태·태양계·연소와 전기·광합성과 힘 등). 정답을 맞히면 골드·지능(과 소량의 창의력)이 오르고 콤보가 쌓일수록 보상이 커지며, 틀리면 체력이 깎이고 스트레스가 오르며 콤보가 초기화됩니다. 지능이 높아질수록 더 높은 레벨의 문제가 열리며, "공부"를 고르면 어떤 과목·레벨이 나올지 직접 정하지 않고 매 문제마다 무작위로 정해집니다(항상 쉬운 레벨만 골라 안전하게 콤보를 쌓는 것을 막기 위함). 운동·휴식에도 보너스 문제가 1개씩 딸려 나와, 맞히면 추가 효과를 더 받을 수 있습니다(틀려도 원래 효과는 그대로 받으니 부담은 없습니다).

이렇게 번 돈은 상점의 "장비" 탭에서 학용품(샤프/태블릿/티아라/왕실 초대장/AI 학습기/개인 오케스트라 레슨)과 집(아파트/단독주택/별궁)을 사는 데 쓸 수 있고, 각각 골드·지능 획득량, 연회 매력 획득량, 인물 호감도 획득량, 휴식 효과를 영구적으로 강화합니다. 매력·창의력·지능을 섞은 "품위" 점수가 오르면 옷이 평범한 옷 → 단정한 옷 → 예쁜 드레스 → 공주 드레스 → 무도회 드레스 → (만점에서만 해금되는) 대관식 드레스까지 총 6단계로 자동으로 해금·환복되며, 단계마다 실제로 그린 일러스트 초상화가 금색 액자 프레임에 담겨 표시됩니다(6단계 전부 실제 그림이 준비되어 있으며, 혹시 이미지가 없는 단계가 생기면 자동 생성 SVG 초상화로 자연스럽게 대체됨). 메인 화면의 캐릭터 초상화는 옛 프린세스 메이커 시리즈처럼 캐릭터가 크게 보이도록 액자를 키워뒀습니다. 한 번 해금한 옷은 상점의 "옷장" 탭에서 언제든 원하는 것으로 자유롭게 갈아입을 수 있습니다(엔딩 판정과 인물 해금은 실제 품위 점수 기준이라 코스튬 변경과 무관하게 유지됨).

지능/집중력/체력/매력/창의력/행운 6개 능력치는 값이 20/40/60/80을 넘을 때마다 Lv.1~5로 레벨업하며, 능력치 막대 색이 회색 → 파랑 → 보라 → 핑크 → 금색으로 단계적으로 화려해지고 화면 위에 "🎉 OO Lv.N 달성!" 토스트가 떠서 성장을 바로 체감할 수 있습니다(스트레스는 낮을수록 좋은 지표라 이 레벨업 시스템에서 제외).

만날 수 있는 사람도 친구/라이벌/선생님에서 시작해 사교계 친구·왕자님·왕실 스승까지 점점 넓어집니다. 특정 인물과 호감도를 80 이상 쌓으면 그 관계로 이어지는 히든 엔딩이 열리며, 그중 왕자님과 가까워지고 품위까지 충분히 쌓으면 최고 엔딩인 "진짜 공주가 되다"에 도달합니다. 인물 호감도는 숫자와 함께 삼국지 시리즈의 "친밀도"처럼 낯선 사이 → 아는 사이 → 친근한 사이 → 가까운 사이 → 각별한 사이 5단계 이름으로도 표시되며, 한동안 만나지 않고 방치한 인물은 호감도가 서서히 식으므로(2턴 이상 공백 시 매턴 소폭 감소) 꾸준히 자주 만나야 관계가 유지·발전합니다.

스케줄에는 "연회 참석"도 고를 수 있는데, 실제 사교 예절(인사, 식사 예절, 경청, 감사 인사, 시간 약속 등)을 묻는 3문제짜리 객관식 퀴즈로 진행됩니다. 정답을 맞힐 때마다 매력이 오르고, 3문제를 모두 맞혀야 품위 점수와 무관하게 왕자님을 직접 만나 호감도가 크게 오릅니다(난이도 상향: 기존 2문제 이상 → 3문제 전부). 왕자님은 이 외에도 "친구 만나기"를 통해 품위·호감도 조건에 따라 순서대로 열리는 별도 이야기(호숫가에서 다친 강아지 돌보기 → 대무도회에서 함께 춤추기)로 더 깊은 관계를 쌓을 수 있어, 자연스럽게 예절을 익히며 왕자님과 점점 가까워지는 재미를 줍니다.

"친구 만나기"에서 각 인물마다 조건(품위·능력치·다른 인물과의 호감도)을 만족하면 일반 대사 대신 한 번뿐인 특별한 이야기(퀴즈/1회성 이벤트/선택형 대화)가 먼저 진행됩니다. 정원에서 길 잃은 아기 고양이를 구해주는 이야기(친구), 라이벌과의 쿠키 만들기 대결과 퀴즈 대결, 사교계 친구의 다과회 초대 두 편, 왕실 스승님의 지혜 시험과 서고의 비밀, 왕자님과의 호숫가 산책·장미 정원 산책·대무도회, 친구의 생일 파티, 그리고 품위 만점에서 열리는 대관식 무도회까지 총 14편이 실제 일러스트와 함께 들어 있으며, 각 인물마다 조건을 만족하는 순서대로 이어지고 한 번 완료하면 이후에는 다시 일반 대사로 돌아갑니다.

48턴이 끝나면 최종 능력치(지능/집중력/체력/매력/창의력/스트레스/행운)와 인물 호감도에 따라 17가지 엔딩 중 하나로 마무리됩니다. `?turns=N` 쿼리 파라미터로 총 턴 수를 조절할 수 있습니다(테스트/데모용).

- `math-princess/index.html` — 화면 구조 (시작 / 메인 허브 / 스케줄 / 상태 / 상점(장비·옷장) / 문제풀이 / 세션 요약 / 이벤트 / 선택형 이야기 / 엔딩)
- `math-princess/style.css` — 스타일
- `math-princess/problems.js` — 수학 레벨별(1~10) 문제 생성 엔진(플러그인 방식, DOM 비의존), 정답 판정
- `math-princess/subjects.js` — 영어·과학 레벨별(1~4, 초4~중1) 문제 생성 엔진(DOM 비의존). 정답 판정은 problems.js의 checkAnswer를 그대로 재사용
- `math-princess/endings.js` — 최종 능력치 기반 엔딩 판정 로직(DOM 비의존)
- `math-princess/portrait.js` — 품위 단계별 캐릭터 SVG 초상화 생성기(DOM 비의존, 실제 일러스트가 없을 때의 대체용, 0~5 총 6단계)
- `math-princess/scenarios.js` — 시나리오(quiz/narrative/branching) 콘텐츠용 표준 자료구조와 검증 함수(DOM 비의존). 실제 플레이 가능한 시나리오 14편 포함(새 예고편이 추가되면 상태 화면 "다가오는 이야기" 섹션에 잠금 카드로 미리 보여준다)
- `math-princess/assets/scenarios/{id}/*.png` — 시나리오별 실제 일러스트 장면 이미지
- `math-princess/assets/portraits/tier0~5.png` — 품위 단계별 실제 일러스트 초상화(6단계 전부)
- `math-princess/assets/wardrobe/tier0~5.png` — 옷장 탭에 쓰이는 옷 썸네일 이미지(6단계 전부)
- `math-princess/assets/npcs/{id}.png` — 인물별 초상화(친구/라이벌/선생님/사교계 친구/왕자님/왕실 스승 6명 전부 적용됨)
- `math-princess/script.js` — 스케줄/실행 메뉴, 활동별 능력치/골드 반영, 콤보, 랜덤 이벤트, 능력치 레벨업, 옷장/상점, 상태 화면(다가오는 이야기 포함), 로컬 저장/이어하기

`problems.js`와 `endings.js`는 DOM에 의존하지 않는 순수 로직이라 Node.js에서 바로 불러와 유닛 테스트할 수 있습니다(레벨 1~10 문제 수백 개 자동 채점, 엔딩 판정 케이스 검증 완료).

각 게임 화면 왼쪽 위의 "🏠 홈으로" 버튼을 누르면 다시 게임 선택 화면으로 돌아옵니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 후, 홈 화면에서 원하는 게임을 골라 플레이하면 됩니다. (모바일 화면 크기에서 가장 잘 보입니다.)
